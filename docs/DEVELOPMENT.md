## 二、数据源清单（★ 最重要的工程知识）

**核心事实：东方财富的 K 线域名 `push2his.eastmoney.com` 会直接拒绝来自数据中心网络（GitHub Actions、各类云沙箱）的连接。** 这不是 IPv6 问题、不是限流、不是 Bun 的 fetch 缺陷（一代文档的假设全部被实测推翻，证据见第五节）。拒绝表现为瞬间连接失败而非超时；偶尔会有放行窗口（这解释了原版 main.ts 曾经跑通的「矛盾」），**绝不可依赖**。

实测验证过的接口矩阵（2026-08-03，数据中心网络环境）：

| 用途 | 接口 | 数据中心可达性 | 备注 |
| --- | --- | --- | --- |
| **个股/指数日K（主源）** | `https://proxy.finance.qq.com/ifzqgtimg/appstock/app/newfqkline/get?param={sym},day,{beg},{end},{count},{fq}` | ✅ 稳定 | `sym` 形如 `sh600000`/`sz000001`；`fq` 空=不复权、`qfq`=前复权。**不复权行含换手率(第8列)与成交额(第9列,万元)** |
| 日K备用域名 | `https://web.ifzq.gtimg.cn/appstock/app/newfqkline/get`（同参数） | ✅ 稳定 | 与主源同一接口，代码内自动轮换 |
| 全市场名单 | `https://push2delay.eastmoney.com/api/qt/clist/get`（镜像 `push2`、`92.push2`） | ✅ 稳定 | 代码/名称/总股本(f38)/流通股本(f39)，分页 pz=100 |
| 前十大流通股东 | `https://datacenter.eastmoney.com/securities/api/data/v1/get`（reportName=`RPT_F10_EH_FREEHOLDERS`） | ✅ 稳定，**偶发返回空 result**（重试即可） | SECUCODE 形如 `600000.SH` |
| 东财日K | `push2his.eastmoney.com/api/qt/stock/kline/get` | ❌ **拒连（偶有放行窗口）** | 代码中仅作兜底，连败 >20 次后熔断跳过 |
| 东财延时K线 | `push2delay` 同路径 | ⚠️ 可达但 `klines` 恒为空数组 | 不可用 |
| 新浪 | `hq.sinajs.cn` | ❌ 403 | 不可用 |

腾讯行格式（`newfqkline`，`day`/`qfqday` 数组的每行）：
`[0]日期 [1]开盘 [2]收盘 [3]最高 [4]最低 [5]成交量(手) [6]信息对象 [7]换手率% [8]成交额(万元) ...`
**注意**：指数和部分老数据行可能缺第 7/8 列；前复权行也可能缺这两列——所以**成交额/换手率必须从不复权（fq=空）行取**。

请求头：所有请求带 `User-Agent`（普通浏览器 UA）与 `Referer`（腾讯用 `https://gu.qq.com/`，东财用 `https://quote.eastmoney.com/`，股东用 `https://emweb.securities.eastmoney.com/`）。均为公开接口，无需鉴权。

## 三、`src/report-by-date.ts` 设计详解

### 与 main.ts 的本质区别

main.ts 用东财「实时榜单快照」，只能反映当下；report-by-date.ts **不依赖任何快照**：先取全市场名单（约 5545 只），再逐只拉日 K，用指定日期当天的涨跌幅重新排序。因此可回算任意历史交易日。

### 管线（5 个阶段）

1. **参数与校验**：`YYYY-MM-DD` 来自 argv[2] 或环境变量 `REPORT_DATE`/`DATE`；拒绝未来日期（按北京时间）。
2. **交易日校验**：取上证指数 `sh000001` 不复权日K，目标日无K线即退出（区分「非交易日」与「接口失败」两种退出信息）。东财兜底。
3. **全市场回算**（并发 `CONCURRENCY`，默认 8）：每只股票
   - 腾讯**不复权**日K → 当日开/收/成交额/换手率/近5日换手、bars 数（判断新股）；
   - 腾讯**前复权**日K → 当日涨跌幅 = 前复权收盘环比（**官方口径，除权除息日准确**——这是 v2 的关键设计，不要改回「不复权价环比」，除权日会算错）；
   - 上市首日等无前收盘的情况 → 东财兜底取官方涨跌幅字段；仍无则剔除并计数；
   - 换手率缺失时用 `成交量÷流通股本` 推算并打 `*` 标注（turnEst）。
   - 有效样本 < 100 只即中止，不产出不完整报告。
4. **入选 200 只明细**（并发 6）：半年前复权收盘价（画图）+ 前十大流通股东（只取报告期 ≤ 指定日期的最新一期，**不用未来数据**）。股东接口偶发空响应：首轮每只重试 2 次，跑完后对仍为「数据源无该股流通股东数据」者做**串行补漏**（间隔 800ms，再试 3 次）。`bars ≤ 20` 的判定为新股，提示「上市初期新股，尚未披露定期报告」——这是事实而非故障。
5. **生成 HTML**：手写内联 SVG 走势图（300×80 polyline，涨 `#c0392b` 跌 `#1e8449`）；报告头部完整披露口径与局限（历史市值=当日收盘×**当前**股本属推算、退市股不在样本、股东数据披露期等）。只写 `reports/${DATE}.html`。

### 诚实性原则（用户明确重视，必须延续）

- 取不到的数据显示 `—` 并注明原因，**不编造、不臆测**；
- 推算值（市值、换手率*）必须标注；
- 报告口径说明必须与实际实现一致，改代码时同步改说明文字。

### 关键实现细节速查

- `symTX(code)`：`6` 开头 → `sh`，否则 `sz`；`secidEM(code)`：`6` 开头 → `1.`，否则 `0.`。（**二期若加北交所，两处都要扩展**）
- 股票池 `FS = "m:0+t:6,m:0+t:80,m:1+t:2,m:1+t:23"`：深主板、创业板、沪主板、科创板，**不含北交所**。
- `getJSON()`：重试 n 次、退避 `700*(i+1)`ms、**每次重试新建 `AbortSignal.timeout(20000)`**（一代版本复用同一 signal 是隐藏 bug，已修，勿回退）。
- `emKlineDead` 熔断：东财兜底连续失败 >20 次后直接跳过，防止在拒连环境把运行拖到 40 分钟（一代曾因重试乘法效应跑了 39 分钟）。
- 腾讯域名轮换 `txHostIdx`：首选域名异常自动切到备用并记住。

### 性能基线（真实数据）

全市场 5545 只、并发 8：完整一跑约 **13–15 分钟**（本地实测三次），Actions 上量级相同。筛选阶段每只 2 个请求（raw + qfq），明细阶段每只 2–3 个。**调并发或重试次数前先算请求总量**：`5545 × 2 × 重试数`，乘法效应会失控。

## 五、一代假设的勘误（避免后人走回头路）

一代文档的主假设是「push2his DNS 优先返回 IPv6，GitHub runner IPv6 不通，Bun fetch 不做 happy-eyeballs 回落」。**实测推翻**：

- 强制 IPv4（`--resolve` 直连各真实 IP）同样瞬间被拒 → 与 IPv6 无关；
- curl 与 Bun fetch 表现一致 → 与 Bun 无关；
- `dns.setDefaultResultOrder("ipv4first")` 预载层无效 → 方向本身就错了。

「原版 main.ts 曾在 Actions 跑通」的矛盾解释：**东财对数据中心网段的封锁存在放行窗口**（探测中观察到 200 与拒连交替出现）。所以任何「今天试了一下能通」都不构成 push2his 可用的证据。结论：**主源必须是腾讯，东财 K 线只能当兜底。**

一代的 `test/net-hardening.ts` 预载方案已废弃，其中唯一有价值的发现（AbortSignal 复用缺陷）已合并进 v2 本体。

当前通过 Tasklet 的 GitHub 连接操作仓库，能力与一代不同（一代用的是另一套工具）：

- 观测 Actions 结果的唯一通道：让工作流把日志/产物 `git commit` 回仓库，再读文件轮询。

### 坑列表

| 坑 | 对策 |
| --- | --- |
| `.gitignore` 含 `*.log`，日志被静默忽略，工作流「绿了」但啥也没提交 | 产物一律 `.txt`/`.html` 后缀，必要时 `git add -f` |
| 工作流内 git 提交失败 `exit 128` 会丢掉全部日志 | 提交步骤自带重试且 `exit 0`，别让提交失败拖垮 job |
| push2his「今天能通」 | 是放行窗口假象，见第五节，别据此改回东财主源 |
| 腾讯前复权行缺换手率/成交额列 | 这两个字段只能从不复权行取 |
| 指数行列数与个股不同 | 指数只用日期/收盘，别读第 7/8 列 |
| 单一 `AbortSignal` 复用于多次重试 | 触发一次后后续重试瞬间全败；每次重试必须新建 signal |
| 重试次数的乘法效应 | 外层重试 × 内层重试 × 5545 只，改前先估算总请求量 |
| 新股无股东数据 | 是事实不是 bug，`bars ≤ 20` 已有专门文案 |
| 沙箱 `/tmp` 是易失的 | 持久产物放 `/tasklet/agent/home/stock/`（本地镜像）并推 GitHub |
