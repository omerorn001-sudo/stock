# 指定日期报告（历史回算版）

脚本：`src/report-by-date.ts`。**原有 `src/main.ts` 和每日定时工作流完全未动。**

## 为什么需要新脚本

`src/main.ts` 的榜单来自东方财富的**实时/延时行情快照接口**，该接口只有"当下"一个断面，不接受日期参数，因此无法回溯历史。

`src/report-by-date.ts` 改用另一条路径：

1. 用上证指数日K校验指定日期是否为交易日（不是则报错并提示最近的交易日）；
2. 分页拉取**全市场沪深A股名单**（含总股本、流通股本）；
3. 对**每一只股票**拉取日K，取当日的涨跌幅/收盘/开盘/成交额/换手率；
4. 按当日涨跌幅重新排序，取前100与后100；
5. 对入选的200只再拉前复权半年K线（画走势图）与前十大流通股东。

## 数据源（v2，2026-08-03 修复）

东方财富的 K 线域名（`push2his.eastmoney.com` 及其镜像）**会拒绝来自数据中心网络（含 GitHub Actions）的连接**，在本地能跑、Actions 上必挂。v2 起：

| 数据 | 主源 | 兜底 |
| --- | --- | --- |
| 个股/指数日K | 腾讯财经 `proxy.finance.qq.com` | `web.ifzq.gtimg.cn`，再兜底东财（若可达） |
| 全市场名单（含股本） | 东财 `push2delay.eastmoney.com`（数据中心可达） | `push2` / `92.push2` 镜像 |
| 前十大流通股东 | 东财 `datacenter.eastmoney.com`（数据中心可达） | 空响应自动重试 |

腾讯不复权日K直接提供**当日换手率与成交额**，无需推算；**涨跌幅由前复权连续收盘价环比计算**，与行情软件官方口径一致（除权除息日亦准确）。上市首日等无前收盘的个股会尝试东财官方涨跌幅，仍取不到则不参与排序并在报告中注明数量。

## 用法

本地：

```bash
bun run src/report-by-date.ts 2026-07-29
# 或
REPORT_DATE=2026-07-29 bun run src/report-by-date.ts
# 可选：降低并发（默认 8）以避免限流
CONCURRENCY=6 bun run src/report-by-date.ts 2026-07-29
```

输出：`reports/YYYY-MM-DD.html`（**不会改写 `reports/latest.html`**，不影响每日任务产物）。

GitHub 上手动跑：**Actions → A股指定日期报告（手动）→ Run workflow**，填入日期即可。

## 耗时与限制

- 全市场约 5500 只股票，每只 2 次请求（不复权 + 前复权），入选 200 只再各 2 次，共约 1.1 万次请求；并发 8 时实测约 **7～10 分钟**。工作流已设 timeout 60 分钟。
- 若当日有效样本不足 100 只，脚本直接报错退出，**不会产出残缺报告**。

## 口径说明（报告页内也会写明）

| 项目 | 口径 |
| --- | --- |
| 收盘/开盘/成交额/换手率 | 不复权日K原始字段，与行情软件当日排行榜一致 |
| 涨跌幅 | 前复权连续收盘价环比（＝官方口径，除权除息日亦准确） |
| 走势图 | 前复权收盘价，截至指定日期的近半年 |
| 流通/总市值 | **推算值** = 当日收盘价 × 当前股本；期间发生增发/回购会有偏差 |
| 样本范围 | 当前仍在市的沪深A股；**指定日期之后已退市的个股不在样本内** |
| 前十大流通股东 | 取报告期**不晚于指定日期**的最新一期，不使用未来数据 |
| 缺失数据 | 一律显示 `—` 并注明原因，不编造、不臆测 |
